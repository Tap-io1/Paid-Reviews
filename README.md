# PaidReviews RP

Ελληνικό, στατικό site για κοινότητα GTA RP. Δεν απαιτεί εγκατάσταση, build, βάση δεδομένων ή κλειδιά API.

## Δημοσίευση στο GitHub Pages

1. Δημιούργησε ένα νέο repository στο GitHub, π.χ. `paidreviews-rp`.
2. Ανέβασε **τα περιεχόμενα** αυτού του φακέλου στη ρίζα του repository. Το `index.html` πρέπει να είναι στη ρίζα και το λογότυπο μέσα στο `assets`.
3. Άνοιξε **Settings → Pages → Build and deployment**.
4. Στο **Source**, επίλεξε **Deploy from a branch**.
5. Επίλεξε **main** και **/ (root)**, και πάτησε **Save**.
6. Όταν ολοκληρωθεί η δημοσίευση, το GitHub θα εμφανίσει τον σύνδεσμο του site στην ίδια σελίδα.

Οι σχετικές διαδρομές των αρχείων επιτρέπουν τη λειτουργία και κάτω από το όνομα του repository.

## Αλλαγές

- Κείμενα και Discord invite: `index.html`.
- Χρώματα, γραμματοσειρές και διάταξη: `styles.css`.
- Αντιγραφή εντολών: `script.js`.
- Λογότυπο: `assets/logo.png`.

Άνοιξε το `index.html` για τοπική προβολή. Η αντιγραφή εντολών λειτουργεί όταν ο browser επιτρέπει την πρόσβαση στο clipboard (όπως σε HTTPS στο GitHub Pages)· διαφορετικά εμφανίζεται οδηγία χειροκίνητης πληκτρολόγησης.

## Περιεχόμενο και λειτουργίες

Η σελίδα παρουσιάζει εικονικές αποστολές και credits του GTA RP. Δεν υλοποιεί bot, λογαριασμούς, πραγματικό balance, αιτήματα εξαργύρωσης ή πληρωμές. Οι σχετικές ενέργειες γίνονται στο Discord. Δεν έχουν προστεθεί screenshots από το Discord, καθώς δεν παραδόθηκαν.

Το υλικό προσαρμόστηκε στο δηλωμένο πλαίσιο του παιχνιδιού: αφαιρέθηκαν αναφορές σε πραγματικές αξιολογήσεις Google, πολλαπλούς λογαριασμούς Google, αλλαγές σύνδεσης και πραγματικές πληρωμές PayPal / paysafe.
